# 마비옛체 (Mabinogi Classic)

`Mabinogi_Classic_OTF.otf` 는 **넥슨이 배포하는 파일 그대로**다. 열지도 고치지도 변환하지도 않았다.

| 항목 | 값 |
|---|---|
| 출처 | https://mabinogi.nexon.com/page/pds/font.asp |
| 원본 주소 | https://mabinogi.vod.nexoncdn.co.kr/font/Mabinogi_Classic_OTF.otf |
| 크기 | 730,444 바이트 |
| SHA-256 | `df735d3b858af729ac081746cdefe797583791971926cd7796cab0ab00f3400a` |
| 확인일 | 2026-09-09 (CDN 원본과 바이트 단위 일치 확인) |

## 왜 woff2 로 줄이지 않았나

넥슨 사용 조건이 **「임의로 수정, 편집 등을 할 수 없으며 배포되는 형태 그대로 사용해야 합니다」**라고 못박는다.
woff2 변환은 배포 형태를 바꾸는 일이라 하지 않았다. 730KB 를 그대로 받는 편이 안전하다.

## 왜 넥슨 CDN 을 직접 링크하지 않았나

`https://mabinogi.vod.nexoncdn.co.kr` 응답에 `Access-Control-Allow-Origin` 헤더가 없다(2026-09-09 확인).
브라우저가 교차 출처 `@font-face` 를 막으므로 직접 링크는 동작하지 않는다.
같은 조건이 **「저작권 안내를 포함해서 다른 소프트웨어와 번들하거나 임베디드 폰트로 사용하실 수 있습니다」**라고
임베디드 사용을 명시적으로 허용하므로, 파일을 그대로 담아 쓴다.

## 출처 표기

조건이 출처 표기를 권장한다. 허브 페이지 맨 아래에 한 줄로 적어 두었다.
지우지 말 것 — 「이 페이지에는 마비노기가 제공한 마비옛체 서체가 적용되어 있습니다.」

**2026-09-21: 그 문장 오른쪽에 「출처 ↗」 링크를 붙였다**(영어 블록은 「Source ↗」).
글로만 적어 두면 어디서 받은 서체인지 확인할 방법이 없다는 지적을 받아서다.
주소는 위 표의 출처와 같은 `https://mabinogi.nexon.com/page/pds/font.asp` 이고,
같은 날 열어 자료실 「마비옛체 서체」 페이지가 살아 있는 것을 확인했다(EUC-KR 페이지라 인코딩을 지정해야 본문이 읽힌다).
회색 안내문 안에 있어 색만으로는 링크로 안 보이므로 `index.html` 에서 밑줄을 남겼다.

## 어디에 쓰나

제목에만 쓴다(`h1`, 게임 이름, 절 제목). 본문·법률 문서 본문에는 쓰지 않는다.
장식용 서체라 긴 글의 가독성이 떨어지고, 라틴 문자·숫자는 기본 서체가 더 낫기 때문이다.
