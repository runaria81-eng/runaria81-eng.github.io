2. 처리 항목·목적·보관 기간

  • 게임 진행과 최고점: 단계, 점수, 남은 시간 및 이어하기에 필요한 플레이 상태를 기기 브라우저에 저장합니다. 목적은 진행 복원과 최고점 표시이며, 이용자가 삭제하거나 새 기록으로 교체될 때까지 남습니다.
  • 환경설정: 언어, 소리 켜짐 여부, 음악·효과음 볼륨을 같은 브라우저에 저장합니다. 설정 적용에 사용하며 변경·삭제 시까지 보관됩니다.
  • 이메일 문의: 이용자가 직접 보낸 이메일 주소, 문의 내용과 첨부자료를 답변과 문제 해결에 사용합니다. 문의 처리에 필요한 기간 동안 보관하고 필요가 없어지면 삭제합니다. 법령상 보존 의무가 있는 자료는 해당 법정 기간에 한해 별도로 보관합니다.

3. 직접 수집하지 않는 정보

현재 게임은 계정 서버, 클라우드 저장, 온라인 랭킹을 제공하지 않습니다. 게임 코드에는 이름·전화번호·주소·연락처·사진·정확한 위치를 요청하는 기능이 없습니다. 로컬 게임 저장은 운영자 서버로 전송되지 않습니다. 이 설명은 외부 호스팅 사업자가 접속 과정에서 처리하는 기술 기록까지 없다는 의미는 아닙니다.

4. 브라우저 저장과 삭제

게임은 브라우저의 로컬 저장소(localStorage)를 사용합니다. 브라우저 설정의 개인정보 또는 사이트 데이터 관리에서 이 게임 주소의 데이터를 삭제하면 진행·최고점·언어·음량 설정을 지울 수 있습니다. ‘새 게임’은 진행 기록을 새로 시작하지만 모든 환경설정을 지우는 기능은 아닙니다. 브라우저별 저장소가 다르므로 사용한 브라우저마다 삭제해야 합니다. 서버 백업이 없어 삭제한 진행은 운영자가 복구할 수 없습니다.

5. 광고·분석·결제

현재 기본 웹 실행에는 실광고, 이용 분석 및 결제 사업자의 SDK가 연결되어 있지 않습니다. 따라서 현재 게임 코드가 광고 ID나 구매 내역을 해당 서비스로 전송하지 않습니다. 향후 해당 기능을 제공하는 버전은 실제 처리 항목, 목적, 제공자와 필요한 동의 절차를 적용 전에 안내합니다.

6. 외부 사이트와 호스팅

공개 약관 페이지의 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록합니다. 이는 게임의 로컬 저장과 별도이며, 처리·보관 기준은 GitHub 개인정보 처리방침을 따릅니다. 다른 호스팅이나 배포 플랫폼을 통해 접속하면 그 사업자도 서비스 제공·보안에 필요한 접속 정보를 처리할 수 있습니다. 관련 근거: GitHub Pages 공식 안내.
