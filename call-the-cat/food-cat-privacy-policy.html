Privacy Policy

Food Cat · Dodo’s Fish Delivery
Last updated: September 5, 2026

This policy applies to the Food Cat web game and future versions distributed through Apps-in-Toss, Google Play, and Apple App Store.

1. Operator and contact

Operator: Baren81. Privacy questions can be sent to barendevlog@gmail.com.

2. Local game data

Food Cat stores game progress, language, and sound preferences locally in the browser or app on the device. The current game does not operate an account server and does not request a name, phone number, contacts, photos, precise location, or payment information.

3. Advertising, analytics, and release changes

The current web game has no live advertising or analytics SDK. If a release version adds advertising, analytics, login, payments, or a platform service, this policy will be updated before release to identify the provider, information categories, purpose, retention, and available privacy controls. Where required, consent will be requested before the relevant SDK starts.

4. Storage and requests

Local data can be removed through the game’s New Game action or browser/app storage controls. If you email the operator, your email address and message are used only to respond to the request and are kept only as long as needed, unless a longer period is required by law.

5. Children, security, and changes

The game does not create an account server for children. Age ratings, parental controls, consent, and child-safety requirements follow the target platform and applicable law. We update this page when the data flow or platform services change.

2. 로컬 게임 데이터

Food Cat은 게임 진행, 언어와 사운드 설정을 브라우저 또는 기기의 앱에 로컬 저장합니다. 현재 게임은 계정 서버를 운영하지 않으며 이름, 전화번호, 연락처, 사진, 정확한 위치 또는 결제수단 정보를 요청하지 않습니다.

3. 광고·분석과 출시 변경

현재 웹 게임에는 실제 광고·분석 SDK가 연결되어 있지 않습니다. 출시 버전에 광고, 분석, 로그인, 결제 또는 플랫폼 서비스를 추가하면 제공자, 정보 항목, 목적, 보관, 개인정보 제어 방법을 적어 출시 전에 이 방침을 갱신합니다. 필요한 지역에서는 관련 SDK를 시작하기 전에 동의를 받습니다.

4. 저장·삭제·요청

로컬 데이터는 게임의 새 게임 기능이나 브라우저·앱 저장소 관리 기능으로 삭제할 수 있습니다. 운영자에게 이메일을 보내면 답변을 위해 이메일 주소와 문의 내용을 처리하며 법령상 더 긴 보관이 필요한 경우를 제외하고 필요한 기간만 보관합니다.

5. 아동·보안·변경

게임은 아동을 위한 계정 서버를 만들지 않습니다. 연령 등급, 보호자 통제, 동의와 아동 보호 요건은 대상 플랫폼과 관련 법령을 따릅니다. 데이터 흐름이나 플랫폼 서비스가 바뀌면 이 페이지를 갱신합니다.
